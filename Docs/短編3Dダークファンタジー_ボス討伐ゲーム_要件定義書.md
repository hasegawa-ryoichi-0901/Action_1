# 要件定義書：短編3Dダークファンタジー・ボス討伐ゲーム

## 0. ディレクター方針

この企画は、**「ソウルライクを作る」のではなく、「30分で濃いボス戦体験を作る」**企画である。

開発条件は以下の通り。

| 項目 | 内容 |
|---|---|
| 開発期間 | 1年 |
| 作業時間 | 1日1時間程度 |
| 開発方針 | アセット使用前提 |
| 開発エンジン | Unreal Engine 5.x |
| 目標 | Steamで公開可能な最小完成版、またはポートフォリオ作品 |

1年・1日1時間の場合、単純計算では約365時間あるが、調査・詰まり・作り直し・体調不良・ビルド対応を考慮すると、実制作に使える時間は**250〜300時間前後**で見るべきである。

そのため、本企画では以下を厳守する。

- ボスは1体
- マップは1つ
- 武器は1種類
- 雑魚敵は2〜3種類まで
- プレイ時間は15〜30分
- 複雑なストーリー、装備収集、クラフト、オンライン要素は入れない

## 2. コンセプト

**暗い神殿を探索し、準備を整え、封印された番人を倒す短編アクションゲーム。**

プレイヤー体験の核は以下。

| 体験 | 内容 |
|---|---|
| 緊張感 | 回復回数が限られ、敵の攻撃を観察して避ける |
| 達成感 | ボスの攻撃パターンを覚えて勝つ |
| 探索感 | 小さなマップ内で強化素材や回復アイテムを探す |
| 雰囲気 | 朽ちた神殿、呪い、暗い森、失われた騎士 |

本作の売りは、**広さではなく密度**である。  
プレイヤーに「短いが、1本のゲームとして遊び切った」と感じさせることを最優先にする。

---

## 3. ターゲット

| 項目 | 内容 |
|---|---|
| 想定ユーザー | 高難度アクション、ダークファンタジー、ボス戦が好きなPCゲーマー |
| 年齢層 | 15〜35歳程度 |
| 好む体験 | 回避、攻撃タイミング、探索、ボス攻略 |
| 参考嗜好 | ELDEN RING、DARK SOULS、Sekiro、ENDER LILIES、Hollow Knight系の緊張感 |

ただし、ターゲットはソウルライク好きでも、**ゲーム規模はソウルライクにしない**。  
ここを混同するとスコープが肥大化し、完成しなくなる。

---

## 4. スコープ定義

### 4.1 作るもの

| 分類 | 要件 |
|---|---|
| プレイヤー操作 | 移動、回避、通常攻撃、ロックオン、回復 |
| 敵 | 雑魚敵2種類、ボス1体 |
| マップ | 小規模な神殿エリア1つ |
| 成長要素 | HP強化、攻撃力強化、回復回数増加 |
| UI | HP、スタミナ、回復数、ボスHP、タイトル、ポーズ、ゲームオーバー、クリア |
| セーブ | チェックポイント到達時に保存 |
| 演出 | ボス登場演出、撃破演出、環境音、最低限のVFX |
| リリース準備 | Windowsビルド、Steamページ用スクショ、短いPV |

### 4.2 作らないもの

| 作らない要素 | 理由 |
|---|---|
| 複数武器 | モーション、調整、UIが増える |
| 装備収集 | インベントリとバランス調整が重い |
| 広大なマップ | レベルデザイン負荷が高すぎる |
| 複数ボス | 1体の品質を上げるべき |
| オンライン要素 | 通信・同期・検証が重い |
| 会話システム | UIとテキスト量が増える |
| クエストシステム | 短編には不要 |
| クラフト | 目的がぼやける |
| マルチエンディング | 工数に対して効果が薄い |

途中で追加したくなった要素は、本編には入れず**Backlog候補**として管理する。

## 5. ゲームフロー

### 5.1 基本フロー

```text
タイトル
↓
神殿入口
↓
チュートリアル敵と戦闘
↓
小探索エリア
↓
強化素材を入手
↓
中ボスではなく強めの雑魚戦
↓
チェックポイント
↓
ボス戦
↓
クリア演出
↓
タイトルへ戻る
```

### 5.2 プレイ時間配分

| 区間 | 想定時間 |
|---|---:|
| 操作確認 | 2〜3分 |
| 探索 | 5〜8分 |
| 雑魚戦 | 3〜5分 |
| 強化判断 | 1〜2分 |
| ボス戦 | 5〜15分 |
| 合計 | 15〜30分 |

## 6. 機能要件

### 6.1 プレイヤー機能

| ID | 要件 | 優先度 |
|---|---|---|
| PL-001 | WASDまたは左スティックで移動できる | 必須 |
| PL-002 | カメラ方向基準で移動できる | 必須 |
| PL-003 | 通常攻撃ができる | 必須 |
| PL-004 | 回避ローリングができる | 必須 |
| PL-005 | 回避中に無敵時間を持つ | 必須 |
| PL-006 | スタミナを消費して攻撃・回避する | 必須 |
| PL-007 | 回復アイテムを使用できる | 必須 |
| PL-008 | 敵をロックオンできる | 強く推奨 |
| PL-009 | 被ダメージ時に怯み・無敵時間が発生する | 必須 |
| PL-010 | 死亡時にチェックポイントから再開する | 必須 |

### 6.2 戦闘機能

| ID | 要件 | 優先度 |
|---|---|---|
| BT-001 | プレイヤー攻撃が敵に命中する | 必須 |
| BT-002 | 敵の攻撃がプレイヤーに命中する | 必須 |
| BT-003 | HPが0になると死亡する | 必須 |
| BT-004 | スタミナが足りない場合、攻撃・回避できない | 必須 |
| BT-005 | 攻撃ヒット時にSE・VFXを再生する | 必須 |
| BT-006 | 敵の予備動作を見て回避判断できる | 必須 |
| BT-007 | ボスのHPバーを表示する | 必須 |
| BT-008 | ボスのフェーズ変化を実装する | 推奨 |

### 6.3 敵AI

| 敵 | 要件 |
|---|---|
| 雑魚A | 近づいて単発攻撃する基本敵 |
| 雑魚B | 少し距離を取り、突進または遠距離攻撃を行う敵 |
| ボス | 3〜5種類の攻撃パターンを持つ大型敵 |

### 6.4 ボス要件

| 項目 | 内容 |
|---|---|
| ボス名 | 神殿の番人 |
| 戦闘時間 | 初見5〜10分、慣れると2〜4分 |
| 攻撃パターン | 横薙ぎ、叩きつけ、突進、範囲攻撃、フェーズ2攻撃 |
| フェーズ | HP50%以下で攻撃パターン追加 |
| 勝利条件 | ボスHPを0にする |
| 敗北条件 | プレイヤーHPが0になる |
| 必須品質 | 攻撃前モーションが読めること |

ボス戦で最も重要なのは、理不尽にしないことである。

- 見てから避けられる
- 失敗理由が分かる
- 次は勝てそうと思える
- 攻撃前モーションが明確
- 被弾した原因がプレイヤーに伝わる

| プレイヤー | Marketplace / Fab等のキャラクターアセット |

| SE/BGM | 商用利用可能なものを使用 |

### 10.2 アセット選定基準

| 基準 | 内容 |
|---|---|
| 商用利用可 | 必須 |
| UE対応 | 必須 |
| アニメーション付き | 強く推奨 |
| 見た目の統一感 | 必須 |
| 改変可能 | 推奨 |
| 軽量 | 推奨 |

アセットは制作時間を0にするものではない。  
見た目の制作時間を減らす代わりに、以下の確認・調整が必要になる。

- ライセンス確認
- UEバージョン対応
- 見た目の統一
- モーションの接続
- 当たり判定調整
- パフォーマンス確認

## 16. リスクと対策

| リスク | 内容 | 対策 |
|---|---|---|
| ボスAIが難航 | 攻撃パターン制御が重い | 最初は3パターンだけにする |
| モーション品質不足 | 攻撃が気持ちよくない | アセット選定時にモーション重視 |
| カメラ事故 | 壁や敵で見づらい | 狭すぎる地形を作らない |
| スコープ肥大化 | 武器・敵・マップを増やしたくなる | 要件外はBacklogへ隔離 |
| UIに時間を取られる | 見た目調整で沼る | 最初は機能優先 |
| Steam準備不足 | ストア素材が間に合わない | 10か月目から準備する |

## 18. ディレクター判断

この企画の成功条件は、**「面白いボス戦が1つあること」**である。

マップが広いことでも、武器が多いことでも、敵が多いことでもない。  
最初の完成版は、以下で十分である。

```text
小さな神殿を歩く
↓
雑魚を倒す
↓
素材で少し強くなる
↓
ボスに挑む
↓
何度か負ける
↓
攻撃を覚えて勝つ
↓
クリア
```

作るべきなのは、未完成の大作ではなく、**完成した小品**である。  
この要件定義なら、1年・1日1時間でも完成を狙える。
