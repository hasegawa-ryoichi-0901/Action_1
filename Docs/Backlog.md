# Backlog

このファイルは、MVP制作範囲から意図的に外した案を管理するためのものです。

## ルール

- backlog 項目は、明示的なスコープ見直しなしに本編へ入れない
- 新しいアイデアはすぐ実装せず、まずここへ追加する
- 優先度が高くても、すぐ着手することを意味しない

## 高

- 難易度選択
- 実績対応
- より厚いボスフェーズ2挙動

## 中

- 2体目のボス
- 2種類目の武器
- 追加の探索分岐
- 敵バリエーション追加

## 低

- NPC会話
- マルチエンディング
- 図鑑 / lore archive
- 収集要素
- 高度なUIテーマ調整

## 保留案

- ゲームパッド専用のカメラ調整
- ボス再戦タイマー表示
- フォトモード
- 基本以上のアクセシビリティ対応
