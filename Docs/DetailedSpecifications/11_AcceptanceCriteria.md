# 受け入れ基準・デバッグ仕様

## 1. MVP受け入れ基準

- タイトルからゲーム開始できる
- プレイヤーが移動、攻撃、回避できる
- 通常敵を倒せる
- ボスと戦える
- ボス撃破でクリアになる
- 死亡時にリトライできる
- `15分以上` の通しプレイが成立する
- Windowsビルドで最後まで遊べる

## 2. 品質受け入れ基準

- ボス攻撃前モーションが分かる
- 被弾理由がプレイヤーに伝わる
- 操作遅延が気にならない
- カメラ事故が頻発しない
- UIが最低限読める
- SEとVFXで命中感がある

## 3. デバッグ表示

開発中は以下を確認できる状態が望ましい。

- プレイヤーHP
- スタミナ
- 敵HP
- ボスHP
- 現在ステート
- チェックポイントID

## 4. 進行不能判定

以下が発生した場合は重大不具合とみなす。

- シーン遷移停止
- リトライ不能
- ボス撃破後にクリアへ進まない
- セーブ/ロード破綻

## 5. 数値目標

| 項目 | 値 |
|---|---:|
| 通しプレイ時間 | 15〜30分 |
| 目標フレームレート | 60 fps |
| 対応解像度 | 1920x1080 |
| 起動時間目標 | 30秒以内 |
| クラッシュ許容回数 | 0 |
| 進行不能許容件数 | 0 |
