# 音・演出仕様

## 1. 必須SE

- 攻撃ヒット
- プレイヤー被弾
- 回避
- 回復
- 決定
- ボス登場
- ボス撃破

## 2. 必須BGM

- タイトルBGM
- 本編環境BGMまたは環境音
- ボス戦BGM

## 3. 必須VFX

- 攻撃ヒット
- 回復
- ボス攻撃強調
- 撃破演出

## 4. 演出方針

- まずは最低限で成立させる
- 命中感に寄与する演出を優先
- 長すぎる演出は避ける
