# 成長・セーブ仕様

## 1. 成長仕様

### 強化項目

| 項目 | 最大段階 | 効果 |
|---|---:|---|
| HP強化 | 2 | 最大HP上昇 |
| 攻撃力強化 | 2 | 与ダメージ上昇 |
| 回復数強化 | 1 | 回復可能回数増加 |

### 素材

| 項目 | 内容 |
|---|---|
| 名称 | 朽ちた聖印 |
| 入手方法 | 探索、敵撃破 |
| 使用場所 | 祈りの間 |

### 数値

| 項目 | 値 |
|---|---:|
| プレイヤー初期HP | 100 |
| HP強化1段階ごとの増加量 | +20 |
| 攻撃力強化1段階ごとの増加量 | +5 |
| 回復数強化増加量 | +1 |
| 探索配置素材数 | 6 |
| 敵Aドロップ素材数 | 1 |
| 敵Bドロップ素材数 | 2 |
| HP強化必要素材 | 2 / 4 |
| 攻撃力強化必要素材 | 2 / 4 |
| 回復数強化必要素材 | 5 |

## 2. 強化ルール

- 上限段階を超える強化は不可
- 素材不足時は決定不可
- 強化結果は即時反映
- 強化実行時に保存対象へ反映

## 3. セーブ仕様

### 保存項目

- チェックポイントID
- HP強化段階
- 攻撃力強化段階
- 回復数強化段階
- 素材所持数
- ボス撃破状態

### 保存タイミング

- チェックポイント到達時
- 強化実行時
- ボス撃破時

### 保存データ数値制約

| 項目 | 値 |
|---|---:|
| セーブスロット数 | 1 |
| 自動保存対象 | 常時 |
| ボス撃破フラグ | true / false |

### ロード方針

- ゲーム開始時に最新状態を読む
- 単一スロット想定でよい
- 短編のため複雑な分岐セーブは不要
