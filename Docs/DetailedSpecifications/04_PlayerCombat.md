# プレイヤー戦闘仕様

## 1. プレイヤー状態

| 状態 | 内容 |
|---|---|
| Idle | 待機 |
| Move | 移動 |
| Attack | 通常攻撃中 |
| Dodge | 回避中 |
| Heal | 回復中 |
| Hit | 被弾中 |
| Dead | 死亡中 |

## 2. 通常攻撃

- 単発攻撃で開始してよい
- 前方近距離にヒット判定を出す
- 判定発生は1回
- 攻撃後に短い後隙を持たせる
- スタミナを消費する

## 3. 回避

- 発動時にスタミナを消費する
- 一定時間無敵
- 無敵終了後は回避後硬直あり
- 回避連打だけで無限に逃げ続けられない調整にする

## 4. 回復

- 使用動作を挟んでからHP回復
- 回復数を1消費
- 0回時は発動しない
- 回復中は被弾リスクを残す

## 5. 被弾

- ダメージ適用
- 怯みまたは軽いノックバック
- 短時間無敵を付与

## 6. 死亡

- HPが0以下で `Dead`
- 入力停止
- 死亡演出または停止
- ゲームオーバー導線へ遷移

## 7. スタミナ

- 攻撃と回避で消費
- 非行動時に自動回復
- 行動不能理由が分かるようUIに反映

## 8. 数値仕様

### 基本ステータス

| 項目 | 値 |
|---|---:|
| 初期HP | 100 |
| 初期スタミナ | 100 |
| 初期攻撃力 | 20 |
| 初期回復数 | 3 |
| 回復量 | 40 |

### 通常攻撃

| 項目 | 値 |
|---|---:|
| スタミナ消費 | 20 |
| 予備動作 | 0.18秒 |
| 攻撃判定持続 | 0.12秒 |
| 後隙 | 0.32秒 |
| ヒット距離 | 2.2 m |
| ヒット角度 | 70 deg |

### 回避

| 項目 | 値 |
|---|---:|
| スタミナ消費 | 25 |
| 回避移動距離 | 3.2 m |
| 回避全体時間 | 0.65秒 |
| 無敵時間 | 0.20秒 |
| 回避後硬直 | 0.18秒 |

### 回復

| 項目 | 値 |
|---|---:|
| 使用開始から回復発生まで | 0.75秒 |
| 回復全体時間 | 1.10秒 |

### 被弾・死亡

| 項目 | 値 |
|---|---:|
| 被弾後無敵時間 | 0.60秒 |
| 被弾硬直 | 0.30秒 |
| 死亡演出時間 | 1.20秒 |

### スタミナ回復

| 項目 | 値 |
|---|---:|
| 回復開始遅延 | 0.80秒 |
| 1秒あたり回復量 | 35 |

## 9. 戦闘品質要件

- 攻撃入力が素直に出る
- 回避成功/失敗が分かる
- 被弾理由が分かる
- スタミナ切れが納得できる
