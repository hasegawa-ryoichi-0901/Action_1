# プレイヤー移動・カメラ仕様

## 1. 移動仕様

- 移動方向はカメラ正面基準で決定する
- 通常移動速度は固定値でよい
- ロックオン中は対象方向を意識した旋回を行う
- 段差や壁に対して過度な引っかかりを出さない

## 2. カメラ仕様

- 通常時は三人称追従
- ロックオン時はプレイヤーと対象が同時に見える構図を優先する
- 壁接近時はカメラ距離を自動で短縮する
- 狭所では埋まりを極力防ぐ

## 3. ロックオン仕様

- 一定距離以内の敵を候補にする
- カメラ前方の敵を優先する
- 対象死亡時は自動解除
- 距離外や遮蔽が強い場合は解除してよい

## 4. 数値仕様

| 項目 | 値 |
|---|---:|
| 通常移動速度 | 4.5 m/s |
| 戦闘時移動速度 | 4.0 m/s |
| 回転補間速度 | 720 deg/s |
| ジャンプ | 未実装 |
| カメラ感度初期値 | 1.0 |
| カメラ距離 | 4.0 m |
| カメラ最小距離 | 2.0 m |
| カメラ最大距離 | 4.5 m |
| ロックオン可能距離 | 12.0 m |
| ロックオン解除距離 | 16.0 m |
| ロックオン視野角 | 70 deg |

## 5. プレイヤー状態との関係

- ロックオンなし: 通常三人称移動
- ロックオンあり: 対象基準の戦闘移動
- 死亡中: カメラ入力を無効化してよい

## 6. 調整方針

- 操作遅延を感じにくいことを優先する
- 見た目の慣性より操作感を優先する
- ボス戦でカメラ事故が頻発する構造は避ける
