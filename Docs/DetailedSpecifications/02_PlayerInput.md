# プレイヤー入力仕様

## 1. 入力一覧

| 入力 | キーボード/マウス | ゲームパッド |
|---|---|---|
| 移動 | `WASD` | 左スティック |
| 視点 | マウス移動 | 右スティック |
| 攻撃 | 左クリック | `X / Square` 相当 |
| 回避 | `Space` | `A / Cross` 相当 |
| 回復 | `R` | `Y / Triangle` 相当 |
| ロックオン | `Q` | `R3` または `LB` 相当 |
| ポーズ | `Esc` | `Start` 相当 |

## 2. 入力ルール

- UI表示中はプレイヤー移動入力を無効化する
- 同時入力時は状態ごとに優先度で解決する
- 長押し前提の操作は基本的に持たない
- キャンセル可否は各アクション側で管理する

## 3. 入力優先度

1. 死亡
2. 被弾
3. ポーズ
4. 回避
5. 攻撃
6. 回復
7. 移動

## 4. 入力の成立条件

### 攻撃

- 死亡中でない
- 被弾硬直中でない
- スタミナが必要量以上ある

### 回避

- 死亡中でない
- 攻撃キャンセル可能時間中、または待機/移動中である
- スタミナが必要量以上ある

### 回復

- 所持回復数が1以上ある
- 致命的な硬直状態でない

## 5. 数値仕様

| 項目 | 値 |
|---|---:|
| 入力バッファ時間 | 0.15秒 |
| ロックオン切替の連打防止時間 | 0.20秒 |
| ポーズ入力の再受付までの時間 | 0.20秒 |
| 回復入力の再受付までの時間 | 0.30秒 |
| 攻撃入力の再受付までの時間 | 0.25秒 |
| 回避入力の再受付までの時間 | 0.20秒 |

## 6. 実装メモ

- `Input System` のアクションマップを `UI` と `Player` で分ける
- 入力を直接処理せず、プレイヤーアクション要求へ変換する
