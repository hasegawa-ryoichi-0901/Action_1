# 敵仕様

## 1. 敵共通仕様

### 状態

| 状態 | 内容 |
|---|---|
| Idle | 待機 |
| Chase | プレイヤー追跡 |
| Attack | 攻撃 |
| Cooldown | 攻撃後硬直 |
| Hit | 被弾 |
| Dead | 死亡 |

### 共通ルール

- 索敵距離内でプレイヤーを認識
- 攻撃距離まで接近して攻撃
- 攻撃前に明確な予備動作を置く
- 被弾時にリアクションする

### 共通数値

| 項目 | 値 |
|---|---:|
| 索敵距離 | 10.0 m |
| 攻撃解除距離 | 14.0 m |
| 被弾硬直 | 0.25秒 |
| 死亡後消滅まで | 1.50秒 |

## 2. 敵A

### 役割

- 最初に戦う基礎敵
- 回避と攻撃差し込みを学ばせる

### 行動

- 直線的に接近
- 単発近接攻撃
- 攻撃後に大きめの隙

### 調整方針

- HP低め
- 攻撃発生遅め
- ダメージ中程度以下

### 数値

| 項目 | 値 |
|---|---:|
| HP | 45 |
| 接近速度 | 3.2 m/s |
| 攻撃距離 | 1.8 m |
| 攻撃予備動作 | 0.55秒 |
| 攻撃判定持続 | 0.15秒 |
| 後隙 | 0.70秒 |
| ダメージ | 12 |

## 3. 敵B

### 役割

- 距離管理を要求する敵

### 行動

- 一定距離で様子を見る
- 突進または中距離攻撃
- 敵Aよりタイミングを遅らせる

### 調整方針

- 敵Aより討伐に時間がかかる
- 読めるが油断すると被弾する

### 数値

| 項目 | 値 |
|---|---:|
| HP | 70 |
| 移動速度 | 3.6 m/s |
| 間合い維持距離 | 4.5 m |
| 突進開始距離 | 5.5 m |
| 攻撃予備動作 | 0.75秒 |
| 攻撃判定持続 | 0.18秒 |
| 後隙 | 0.85秒 |
| ダメージ | 18 |
