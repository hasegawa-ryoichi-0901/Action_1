# ブート・シーン遷移仕様

## 1. 対象

- アプリ起動
- タイトル画面
- ゲーム開始
- リトライ
- タイトル復帰
- クリア遷移

## 2. シーン構成

| シーン | 役割 |
|---|---|
| `Title` | タイトル表示、開始、終了 |
| `Main` | 探索、戦闘、UI、進行状態の保持 |
| `Reload` | リトライ時の再初期化補助 |

## 3. 起動フロー

1. アプリ起動時に `Title` を開く
2. `Start` 選択で `Main` をロードする
3. `Retry` 選択時は必要に応じて `Reload` を経由し、`Main` を再初期化する
4. `Title` 復帰時は戦闘状態、一時状態、UI状態を破棄する

## 4. 画面遷移

### タイトルから開始

- `Start` 入力でゲーム開始
- 初回は新規開始、保存データがあれば続きから再開でもよい

### 死亡からリトライ

- プレイヤー死亡
- ゲームオーバー表示
- `Retry` でチェックポイントから復帰

### ボス撃破からクリア

- ボスHPが0になる
- ボス行動停止
- 撃破演出
- クリアUI表示
- `Title` に戻る

## 5. 要件

- タイトルから `10秒以内` に操作可能
- リトライ時に不要な状態を引き継がない
- クリア時は必ずクリアUIに到達する
- タイトル復帰後にプレイ中の一時状態が残らない

## 6. 数値仕様

| 項目 | 値 |
|---|---:|
| タイトル操作可能までの目標時間 | 10秒以内 |
| `Start` 押下後のロード待機目標 | 5秒以内 |
| ゲームオーバー表示までの遅延 | 1.5秒 |
| `Retry` から復帰完了までの目標 | 4秒以内 |
| ボス撃破後にクリアUIを出すまでの遅延 | 2.0秒 |
| タイトル復帰時のフェード時間 | 0.5秒 |

## 7. 実装メモ

- シーン遷移責務は1か所に集約する
- リトライ時に再初期化すべき対象を明文化する
- `Reload` は必要性が薄ければ後で統合してよい
