# ボス仕様

## 1. 基本情報

| 項目 | 内容 |
|---|---|
| 名称 | 神殿の番人 |
| 戦闘場所 | 祭壇エリア |
| 勝利条件 | ボスHPを0にする |
| 敗北条件 | プレイヤーHPが0になる |
| 初見想定戦闘時間 | 5〜10分 |
| 慣れ後想定戦闘時間 | 2〜4分 |

## 2. ボス状態

| 状態 | 内容 |
|---|---|
| Intro | 登場演出 |
| Idle | 様子見 |
| Approach | 間合い調整 |
| Attack1 | 横薙ぎ |
| Attack2 | 叩きつけ |
| Attack3 | 突進 |
| PhaseShift | フェーズ移行 |
| Phase2Attack | フェーズ2専用 |
| Hit | 被弾 |
| Dead | 撃破 |

## 3. 行動選択

- 近距離: 横薙ぎ、叩きつけ
- 中距離: 突進を含む
- フェーズ2: 追加行動を1つ解禁

## 4. フェーズ

- フェーズ1: 基本3攻撃
- `HP 50%以下`: フェーズ2へ移行
- フェーズ2: 速度上昇または追加攻撃

## 6. 演出

### 登場

- ボスエリア侵入で開始
- 必要なら短時間プレイヤー操作を制限
- 再戦時は短縮または省略可能が望ましい

### 撃破

- HP 0で行動停止
- 撃破演出
- クリアUI表示
- ボス撃破フラグ保存

## 7. 品質要件

- 全攻撃に読める前兆がある
- 回避可能タイミングがある
- 被弾理由が理解できる
- カメラ事故が少ない
