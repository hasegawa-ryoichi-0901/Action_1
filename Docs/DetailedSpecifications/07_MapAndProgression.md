# マップ・進行制御仕様

## 1. エリア構成

| エリア | 内容 |
|---|---|
| 神殿入口 | 導入、操作確認 |
| 外庭 | 敵Aとの基本戦闘 |
| 崩れた回廊 | 探索、素材配置 |
| 祈りの間 | 強化、チェックポイント |
| 祭壇 | ボス戦エリア |

## 2. 進行構造

- 一本道寄り
- 分岐は最大2つ
- ボス前に休憩地点を置く

## 3. 数値仕様

| 項目 | 値 |
|---|---:|
| 総プレイ時間目標 | 15〜30分 |
| 入口からボス前までの初回到達時間目標 | 8〜12分 |
| 分岐数上限 | 2 |
| チェックポイント数 | 1 |
| 配置素材数 | 6 |
| 敵A配置数 | 3 |
| 敵B配置数 | 2 |
| ボス前安全地帯の長さ目安 | 8.0 m |

## 4. チェックポイント

- 到達時に保存
- 死亡時の復帰地点
- 必要であればHP、回復数を復元

## 5. 進行フラグ

- ボス戦開始済み
- ボス撃破済み
- 強化開放済み
- チェックポイント到達済み

## 6. 設計方針

- 迷わせることより密度を優先
- 雰囲気目的だけの不要部屋は作らない
- ボス前導線は短くする
