# UI仕様

## 1. タイトルUI

- `Start`
- `Option`
- `Quit`

## 2. HUD

- プレイヤーHPバー
- スタミナバー
- 回復数表示
- ロックオン対象マーカー

## 3. ボスUI

- ボス戦開始時にボスHPバー表示
- ボス撃破時に非表示

## 4. ポーズUI

- `Resume`
- `Retry`
- `Option`
- `Title`

## 5. ゲームオーバーUI

- `Retry`
- `Title`

## 6. クリアUI

- `Clear`
- プレイ時間
- `Title`

## 7. 方針

- 読みやすさ優先
- 装飾は後回し
- 戦闘中に必要な情報だけを出す

## 8. 数値仕様

| 項目 | 値 |
|---|---:|
| HPバー更新間隔 | 毎フレーム |
| スタミナバー更新間隔 | 毎フレーム |
| ボスHPバー表示開始遅延 | 0.20秒 |
| ゲームオーバーUI表示遅延 | 1.50秒 |
| クリアUI表示遅延 | 2.00秒 |
| ポーズ開閉フェード時間 | 0.15秒 |
| ロックオンマーカー表示サイズ目安 | 48 px |
